# Reference material

Not part of the build. Kept for provenance while the grading heuristics are
still being tuned against real submission results.

- `gradebench.artifact.jsx` — the original single-file artifact this app was
  ported from. The centering tables and the BGS/PSA final-grade engines in
  `../src/grading.js` came from here unchanged; the corner/edge/surface
  aggregation did not, because the artifact only ever had one front photo.
- `handoff-brief.md` — the port brief, including the ten-photo slot map and the
  front/back weighting rules.

Where the shipped app deviates from the brief, the reasons are listed at the
bottom of `../README.md`.
