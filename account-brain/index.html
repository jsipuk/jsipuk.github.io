Settings and data

Security

This page is public, but the data never is: it lives in this browser only, on this device, and no version of it is sent anywhere or committed to the site. This app holds real customer names and things people said in confidence, so encryption is strongly recommended here.

Encryption cannot protect you from someone who has both the device and the passphrase, and a forgotten passphrase means the data is gone.

Auto-lock

Backup

Browsers clear storage and devices get replaced. An encrypted backup is safe to keep in Google Drive because it is ciphertext. Import merges by id, so restoring an older backup will not discard newer work.

Erase

Clears only Account Brain's own storage key. Nothing else in this browser is touched.
