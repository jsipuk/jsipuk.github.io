Lamplight

The runbook is encrypted. Enter the passphrase to read it.

How this is protected. The whole runbook is sealed with AES-GCM-256 under a key derived from your passphrase by PBKDF2-HMAC-SHA256 at 600,000 iterations — the same scheme the rest of this site uses. Nothing is sent anywhere: the decryption happens in this tab. There is no recovery, no reset and no back door — a forgotten passphrase means the content is gone. Once you are in, Save source in the footer downloads the plaintext, so you can always keep a copy somewhere of your own choosing.

Change the passphrase

This re-seals the runbook in your browser and downloads a fresh index.html. Replace the file on the server with it. The old passphrase stops working for the new file only — any copy of the old file still opens with the old passphrase.
