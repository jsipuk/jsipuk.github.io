Settings and data

Security

This page is public, but the data never is: it lives in this browser only, on this device, and no version of it is sent anywhere or committed to the site. Notes here can name real customers, so encryption is recommended.

Encryption cannot protect you from someone who has both the device and the passphrase, and a forgotten passphrase means the data is gone.

Auto-lock

Fill it from Account Brain

A capture tool is worth nothing on day one, which is the main reason they get abandoned. Import an Account Brain backup and every I learned line and open objection arrives here as a note, tagged with its account. Run it again any time: it only adds what is new.

Quotes and promises are deliberately not imported. A quote is as often a proof point as an objection, and guessing the wrong label is worse than no note.

Backup

Browsers clear storage and devices get replaced. An encrypted backup is safe to keep in Google Drive because it is ciphertext. Import merges by id, so restoring an older backup will not discard newer notes.

Erase

Clears only Field Notes' own storage key. Nothing else in this browser is touched.
